# Niyat Thapa | Portfolio

This is my personal portfolio website. It presents my background in finance, data analysis, and business risk through my education, experience, skills, and selected projects.

## Live Website

[https://immortal-ancestor.github.io/](https://immortal-ancestor.github.io/)

## Features

- Responsive design for desktop and mobile screens
- About, skills, experience, education, projects, and contact sections
- Project descriptions, tools, and visuals
- Downloadable resume
- Contact form that opens a prepared email draft
- Smooth navigation and scroll effects

## Built With

- HTML
- CSS
- JavaScript
- GitHub Pages

## Project Structure

- `index.html` — website content and structure
- `style.css` — layout, colours, typography, and responsive design
- `script.js` — navigation, contact form, and interactive features
- `images/` — website images and project visuals
