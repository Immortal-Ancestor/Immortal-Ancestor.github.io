FEATURED PROJECT / FX RISK

Portfolio Currency Exposure Risk Report

I wrote a Python tool that uses FRED exchange rates to put foreign holdings on a common USD basis and flag positions that could cost more than 5% of the portfolio.

  • Python
  • FRED API
  • Scenario analysis
Try the FX simulator View source code
Read the walkthrough and report output
Problem
Which holdings could cause a material loss if their currencies weakened against the US dollar?
My contribution
For DGTR 3720, I wrote the rate conversion, stress test, and risk flagging logic.
Method
Convert each holding to USD, apply a 10% adverse move, and divide its loss by the total portfolio value.
Result
The report ranks holdings by portfolio weight. In the sample run, the EUR holding was the only one flagged.
